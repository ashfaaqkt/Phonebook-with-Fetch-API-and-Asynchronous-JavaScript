# Phonebook App

A modern, responsive phonebook application built using **HTML**, **CSS**, and **JavaScript** (Fetch API & Asynchronous programming). This project allows users to manage contacts efficiently with a clean and premium user interface.

## About This Project

This project was developed as an educational assignment for **Entri Elevate**. It demonstrates the practical application of asynchronous JavaScript, specifically the Fetch API, to handle CRUD (Create, Read, Update, Delete) operations with a backend/stub.

**Assignment:** Entri Assignment (10)

## Features

*   **View Contacts**: Fetch and display a list of contacts from an API.
*   **Add Contact**: Create new contacts with a name and phone number.
*   **Update Contact**: Edit existing contact details.
*   **Delete Contact**: Remove contacts from the list.
*   **Search Functionality**: Filter contacts by name or phone number in real-time.
*   **Responsive Design**: Fully responsive layout that works on desktop and mobile devices.
*   **Premium UI**: Styled with a modern color palette, glassmorphism effects, and smooth animations.

## Technology Stack

*   **HTML5**: Structure and semantic markup.
*   **CSS3**: Custom styling, CSS Grid/Flexbox, and animations.
*   **JavaScript (ES6+)**: Logic, DOM manipulation, Fetch API, and Async/Await.

## How to Run

1.  Clone logic download the repository.
2.  Open `index.html` in your web browser.
3.  *Note: For the Fetch API to work correctly with some external APIs or local JSON files, you might need to run this on a local server (e.g., using Live Server in VS Code).*
